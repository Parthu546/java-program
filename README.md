# Java Programming Practice

## Overview

This repository contains a collection of basic Java programs developed for learning and practicing core Java concepts. These programs cover fundamental programming topics such as conditional statements, loops, mathematical calculations, pattern printing, and user input handling.

## Programs Included

* Hello World
* Factorial Calculation
* Leap Year Check
* Area of Circle
* Compound Interest Calculation
* Quadratic Equation Solver
* Average and Sum Calculator
* Greatest of Three Numbers
* Weekday Finder
* Alphabet Character Check
* Pattern Printing Programs
* Prime Number Programs

## Technologies Used

* Java
* JDK (Java Development Kit)

## Learning Objectives

* Understanding Java syntax
* Working with variables and data types
* Using conditional statements
* Implementing loops
* Handling user input
* Developing problem-solving skills

## How to Run

1. Install Java JDK.
2. Compile the program:

```bash
javac FileName.java
```

3. Run the program:

```bash
java FileName
```
